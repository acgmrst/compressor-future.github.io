    术语表¶

    A¶

    API (Application Programming Interface)

    应用程序编程接口，用于不同软件系统之间的通信。

    ASME (American Society of Mechanical Engineers)

    美国机械工程师协会，制定压缩机相关标准。

    B¶

    比功率

    单位流量消耗的功率，通常以 kW/(m³/min) 表示。

    变频控制

    通过改变电机转速来调节压缩机的运行状态，实现节能运行。

    C¶

    排量

    压缩机每转一圈所能输送的气体体积，通常以 m³/min 表示。

    喘振

    离心式压缩机在低流量下出现的不稳定运行现象。

    冲程

    活塞在气缸内运动的距离。

    D¶

    低压压缩机

    排气压力在0.1-1.0 MPa之间的压缩机。

    多级压缩

    通过多个气缸串联，逐级提高气体压力的压缩方式。

    E¶

    能效比 (COP)

    制冷量与输入功率的比值，用于衡量制冷压缩机的效率。

    欧拉方程

    描述离心式压缩机能量转换的基本方程。

    F¶

    风冷

    通过空气对流来散热的冷却方式。

    浮动环密封

    通过浮动环形成的密封结构，用于防止气体泄漏。

    G¶

    高温压缩机

    适用于高温环境下运行的压缩机。

    工艺气体

    用于特定工业流程的气体，如天然气、氢气等。

    H¶

    高压压缩机

    排气压力在10-100 MPa之间的压缩机。

    回热循环

    利用排气热量预热进气的循环方式，提高效率。

    I¶

    ISO标准

    国际标准化组织制定的压缩机相关标准。

    吸气压力

    压缩机入口处的气体压力。

    J¶

    机械密封

    通过机械接触面形成的密封结构，用于防止气体泄漏。

    级间冷却

    在多级压缩之间设置冷却器，降低气体温度。

    K¶

    开式叶轮

    叶片两侧没有盖板的叶轮结构。

    空气分离

    将空气分离成氧气、氮气等组分的过程。

    L¶

    螺杆压缩机

    通过一对相互啮合的螺杆旋转来压缩气体的压缩机。

    离心式压缩机

    通过叶轮高速旋转产生离心力来压缩气体的压缩机。

    M¶

    迷宫密封

    通过迷宫结构增加泄漏阻力的密封方式。

    名义功率

    压缩机在额定工况下的输入功率。

    N¶

    内压缩

    气体在叶轮内部被压缩的过程。

    能效等级

    衡量压缩机能源效率的等级标准。

    O¶

    排气压力

    压缩机出口处的气体压力。

    喷油润滑

    向压缩腔喷入润滑油的润滑方式。

    P¶

    排量系数

    实际排量与理论排量的比值。

    膨胀过程

    气体体积增大、压力降低的过程。

    Q¶

    气体常数

    与气体性质相关的常数，用于气体状态方程。

    曲轴

    将旋转运动转换为往复运动的轴。

    R¶

    容积效率

    实际吸气量与理论吸气量的比值。

    滚动转子压缩机

    通过转子在气缸内滚动来压缩气体的压缩机。

    S¶

    三级压缩

    通过三个气缸串联进行压缩的方式。

    双级压缩

    通过两个气缸串联进行压缩的方式。

    T¶

    等温压缩

    气体温度保持不变的压缩过程。

    涡轮压缩机

    通过涡轮驱动的压缩机，通常指离心式或轴流式压缩机。

    U¶

    无油压缩机

    不使用润滑油的压缩机，气体纯净。

    卧式压缩机

    气缸水平布置的压缩机。

    V¶

    V型压缩机

    气缸呈V形排列的压缩机。

    容积式压缩机

    通过改变气体体积来提高压力的压缩机。

    W¶

    往复式压缩机

    通过活塞在气缸内往复运动来压缩气体的压缩机。

    涡旋式压缩机

    通过两个相互啮合的涡旋盘运动来压缩气体的压缩机。

    X¶

    效率

    压缩机的能量转换效率，通常以百分比表示。

    卸荷阀

    用于调节压缩机负载的阀门。

    Y¶

    压力比

    排气压力与吸气压力的比值。

    叶轮

    离心式压缩机中用于压缩气体的旋转部件。

    Z¶

    轴流式压缩机

    气体沿轴向流动的压缩机。

    转子

    旋转运动的部件，如螺杆、叶轮等。
