    第2章 往复式压缩机¶

    工作原理¶

    基本概念¶

    往复式压缩机，也称为活塞式压缩机，是最传统且应用最广泛的压缩机类型之一。它通过活塞在气缸内的往复运动来压缩气体。

    工作过程¶

    往复式压缩机的工作过程分为四个阶段：

    1. 吸气过程¶

    当活塞向下运动时，气缸内的容积增大，压力降低。当气缸内压力低于进气管道压力时，进气阀打开，气体进入气缸。

    2. 压缩过程¶

    活塞向上运动，气缸容积减小，气体被压缩，压力升高。此时进气阀和排气阀都处于关闭状态。

    3. 排气过程¶

    当气缸内压力高于排气管道压力时，排气阀打开，高压气体被排出气缸。

    4. 膨胀过程¶

    排气结束后，气缸内可能残留少量高压气体。当活塞再次向下运动时，这部分气体首先膨胀，直到压力低于进气压力时，进气阀再次打开，开始新的循环。

    理论循环¶

    理想循环（等温循环）¶

    在理想情况下，压缩过程是等温的，气体温度保持不变：

    $$W = P_1V_1 \ln\left(\frac{P_2}{P_1}\right)$$

    实际循环（多变循环）¶

    实际压缩过程中，气体温度会升高，遵循多变过程：

    $$W = \frac{n}{n-1}P_1V_1\left[\left(\frac{P_2}{P_1}\right)^{\frac{n-1}{n}} - 1\right]$$

    其中，$n$ 为多变指数，通常在1.2-1.4之间。

    压缩级数¶

    根据压力比的大小，往复式压缩机可以分为：

    • 单级压缩：压力比一般不超过8-10
    • 多级压缩：通过多个气缸串联，逐级提高压力

    多级压缩的优点： - 降低每级的压力比，提高效率 - 减少温度升高，保护设备 - 提高整体性能

    工作特性¶

    压力-流量特性¶

    往复式压缩机的排气压力可以在较大范围内调节，而流量基本保持恒定，因此被称为"恒流量"压缩机。

    效率特性¶

    往复式压缩机的效率较高，尤其是在中高压范围内，是所有压缩机类型中效率最高的之一。

    启动特性¶

    往复式压缩机启动时需要克服较大的惯性力，通常需要配备启动装置，如卸载启动器。

    结构组成¶

    总体结构¶

    往复式压缩机主要由以下几部分组成：

    1. 曲柄连杆机构：将旋转运动转换为往复运动
    2. 气缸组件：气体压缩的场所
    3. 阀门系统：控制气体的吸入和排出
    4. 润滑系统：减少摩擦和冷却部件
    5. 冷却系统：带走压缩产生的热量
    6. 传动系统：传递动力

    核心部件¶

    曲柄连杆机构¶

    这是往复式压缩机的动力转换核心：

    • 曲轴：接收电机动力，做旋转运动
    • 连杆：连接曲轴和活塞
    • 活塞：在气缸内往复运动，压缩气体

    气缸组件¶

    气缸组件包括：

    • 气缸体：气体压缩的容器
    • 气缸盖：封闭气缸顶部
    • 活塞环：密封活塞与气缸壁之间的间隙
    • 活塞杆：连接活塞和连杆

    阀门系统¶

    阀门系统包括：

    • 进气阀：控制气体进入气缸
    • 排气阀：控制气体排出气缸
    • 阀片：阀门的核心部件，通常由弹簧钢制成

    润滑系统¶

    润滑系统的作用：

    • 润滑：减少运动部件之间的摩擦
    • 冷却：带走摩擦产生的热量
    • 密封：增强活塞环的密封效果

    润滑方式主要有： - 飞溅润滑：利用曲轴转动飞溅润滑油 - 强制润滑：通过油泵加压输送润滑油

    冷却系统¶

    冷却系统的作用是带走压缩过程中产生的热量，主要方式有：

    • 风冷：通过风扇和散热片散热
    • 水冷：通过冷却水循环散热
    • 油冷：通过润滑油带走热量

    结构类型¶

    按气缸排列方式分类¶

    类型 特点 应用
    立式 气缸垂直布置，结构紧凑 小型压缩机
    卧式 气缸水平布置，稳定性好 大型压缩机
    V型 气缸呈V形排列，平衡性好 中型压缩机
    W型 气缸呈W形排列，功率大 大型压缩机
    对置式 气缸对称布置，平衡性能好 大型高压压缩机

    按压缩介质分类¶

    • 空气压缩机：压缩空气
    • 制冷压缩机：压缩制冷剂
    • 工艺压缩机：压缩特定工艺气体

    关键技术参数¶

    参数 定义 影响
    气缸直径 气缸的内径 影响排量
    活塞行程 活塞运动的距离 影响排量和力
    转速 曲轴每分钟转数 影响流量和寿命
    压力比 排气压力与吸气压力之比 影响效率和级数

    选型建议¶

    选择往复式压缩机时，应考虑以下因素：

    1. 压力需求：确定所需的排气压力
    2. 流量需求：计算所需的气体流量
    3. 空气质量：是否需要无油压缩
    4. 运行环境：温度、湿度、海拔等
    5. 维护要求：维护周期、备件供应

    应用领域¶

    概述¶

    往复式压缩机因其压力范围广、效率高的特点，在多个领域都有广泛应用。

    工业制造¶

    气动工具与设备¶

    往复式压缩机是气动工具的主要动力源：

    • 气动扳手：汽车维修、机械装配
    • 气动钻：钻孔、攻丝
    • 气动砂轮机：打磨、抛光
    • 喷漆枪：表面喷涂

    典型场景：工厂车间、维修站、建筑施工。

    物料输送¶

    • 气力输送：输送粉末、颗粒状物料
    • 真空上料：从料仓或容器中吸取物料

    典型场景：化工、食品、制药行业。

    制冷与空调¶

    冷库制冷¶

    往复式压缩机在冷库中应用广泛：

    • 小型冷库：便利店、超市冷柜
    • 中型冷库：食品加工厂、物流中心
    • 大型冷库：冷藏仓库、港口冷链

    典型制冷剂：R22、R134a、R404A。

    中央空调¶

    • 活塞式冷水机组：大型建筑空调系统
    • 热泵机组：冬季供暖、夏季制冷

    典型场景：写字楼、商场、医院。

    石油化工¶

    天然气输送¶

    • 长输管线压缩机：天然气管道增压
    • 加气站压缩机：CNG加气站

    压力范围：通常为2-25 MPa。

    石油炼制¶

    • 加氢压缩机：加氢精制、加氢裂化
    • 重整压缩机：催化重整工艺

    典型场景：炼油厂、石化厂。

    能源电力¶

    燃气轮机配套¶

    • 启动压缩机：燃气轮机启动时提供压缩空气
    • 辅助压缩机：提供仪表风、工厂风

    典型场景：燃气电站、联合循环电站。

    氢气压缩¶

    • 燃料电池氢气供应：为燃料电池提供高压氢气
    • 氢气充装：氢气瓶充装

    压力范围：通常为35-70 MPa。

    医疗与科研¶

    医用压缩空气¶

    • 呼吸机：为呼吸机提供压缩空气
    • 麻醉机：为麻醉机提供气源
    • 医院集中供气：医院中央供气系统

    要求：无油、高纯度。

    实验室设备¶

    • 气相色谱仪：提供载气
    • 质谱仪：提供分析用气
    • 高压实验装置：提供高压气体

    要求：高纯度、稳定压力。

    矿山与建筑¶

    矿山通风¶

    • 矿井压风系统：为矿井提供新鲜空气和动力
    • 隧道施工：隧道掘进中的气动设备

    典型场景：煤矿、金属矿、隧道工程。

    建筑施工¶

    • 混凝土喷射：喷射混凝土施工
    • 桩基础施工：气动打桩设备

    典型场景：高层建筑、桥梁工程。

    特殊应用¶

    高压实验¶

    • 材料测试：高压环境下的材料性能测试
    • 深海模拟：模拟深海压力环境

    压力范围：可达数百MPa。

    气体分离¶

    • 空气分离：氧气、氮气生产
    • 稀有气体提取：氩、氖、氪等稀有气体

    典型场景：气体分离厂、空分设备。

    应用案例¶

    案例1：某汽车制造厂¶

    需求：多条生产线的气动工具供气

    解决方案： - 采用3台W-10/8型往复式压缩机 - 总排量30 m³/min，压力0.8 MPa - 配备储气罐和干燥机

    效果：满足全厂气动设备的用气需求，运行稳定可靠。

    案例2：某食品冷库¶

    需求：5000吨冷库制冷
